# Day 2 Assignment
## Reasoning and Acting: Comparing Direct Prompting, Chain-of-Thought, and ReAct

### Student AI Lab Practical

---

## 1. Objective

The objective of this assignment is to compare different approaches for solving problems using Large Language Models (LLMs).

The approaches demonstrated are:

1. Direct Prompting
2. Chain-of-Thought Style Reasoning
3. ReAct Agent
4. Self-Consistency

The assignment also demonstrates the use of an external weather tool with a ReAct agent.

---

## 2. Technologies Used

- Python
- Groq API
- `openai/gpt-oss-20b` model
- Groq Python SDK
- Requests library
- PowerShell
- Virtual Environment (`venv`)
